# 实验执行总结

本文档说明当前 `SNN` 项目主实验的**完整执行顺序、每一步的目的、输入/输出工件以及推荐命令**。所有命令均从项目根目录 `SNN/` 执行。

当前主实验已经将 **ANN 微调阶段使用的 Prefix / Calibration** 与 **ANN 微调完成后用于最终 ANN 评估和 SNN 转换的 Prefix / Calibration** 严格分离，因此请按照本文档给出的顺序执行，不要再使用旧流程中的无 `--stage` 命令，也不要让 SNN conversion 回退到微调前的 shared calibration。

环境安装与依赖配置见 `环境配置.md`。

---

## 1. 当前实验对象与总体流程

当前一共包含 3 个 model-task pair，每个 pair 包含 4 种 ANN 微调模式：

```text
Model-task pair 1:
  Qwen/Qwen3-1.7B-Base + TL;DR

Model-task pair 2:
  Qwen/Qwen3-8B-Base + TL;DR

Model-task pair 3:
  meta-llama/Meta-Llama-3-8B + Tulu 3
```

四种 ANN mode：

```text
vanilla
unaware
phase_aware
gif_aware
```

因此总计：

```text
3 个 model-task pair × 4 个 ANN mode = 12 个 final ANN checkpoint
```

每个 final ANN checkpoint 后续再分别转换为：

```text
Phase SNN
GIF SNN
MTN SNN
```

因此总计：

```text
12 个 ANN checkpoint × 3 种 neuron = 36 个 SNN conversion
```

当前完整实验顺序为：

```text
1. 生成 12 个 resolved config
        ↓
2. 准备固定数据 manifest
        ↓
3. 每个 model-task pair 准备共享的 pre-finetuning 工件
        ├── Rotation / fused Base
        │   └── 自动进行 Base ↔ Rotated logits regression（固定 128 calibration samples）
        ├── ANN-training Prefix
        ├── ANN-training calibration
        └── Vanilla analysis calibration
        ↓
4. 训练 12 个 final ANN checkpoint
        ↓
5. 对每一个 final ANN checkpoint 单独执行 post-finetuning Prefix discovery
        ↓
6. 对每一个 final ANN checkpoint 单独执行 post-finetuning conversion calibration
        ↓
7. 评估 Base baseline
        ↓
8. 评估 12 个 final ANN checkpoint
        ↓
9. 创建 36 个 SNN conversion descriptor
        ↓
10. 运行 36 次 SNN evaluation
        ↓
11. verify_artifacts 校验最终工件
```

必须特别注意：

```text
ANN-training Prefix / calibration
    ≠
Post-finetuning Prefix / conversion calibration
```

二者用途不同，保存目录也不同，不能混用。

## 2. 三类 Calibration 的定义

当前代码中必须严格区分以下三类 calibration。

### 2.1 Vanilla analysis calibration

对象：

```text
Original pretrained Base model
```

条件：

```text
no rotation
no prefix
no activation replacement
```

目的：

```text
用于分析加入 Rotation + Prefix 前后，
每层相同 10 个 activation replacement site 的激活统计如何变化。
```

它**只用于分析**，不用于 ANN training，也不用于 SNN conversion。

当前代码对该阶段只保存 statistics，不生成用于 conversion 的 Phase/GIF/MTN states。

输出目录：

```text
artifacts/<experiment>/<task>/<model>/_shared/seed42/
└── vanilla_original/
    └── vanilla_analysis_calibration/
        └── sites/
```

---

### 2.2 ANN-training calibration

对象：

```text
Rotated / fused Base model
+
ANN-training Prefix
```

目的：

```text
只用于 ANN 微调阶段的 activation replacement。
```

具体使用关系：

```text
vanilla:
  不使用

unaware:
  不使用

phase_aware:
  使用 ANN-training calibration 中的 Phase + Clip states

gif_aware:
  使用 ANN-training calibration 中的 GIF + Clip states
```

因此：

> `unaware` 虽然使用 Rotation + ANN-training Prefix，但训练过程中没有 activation replacement，所以不使用 ANN-training calibration state。

输出目录：

```text
artifacts/<experiment>/<task>/<model>/_shared/seed42/
└── rotated_prefix/
    └── ann_training_calibration/
        └── sites/
```

---

### 2.3 Post-finetuning conversion calibration

对象：

```text
每一个已经完成微调的 final ANN checkpoint
+
该 final ANN checkpoint 自己重新 discover 的 post-finetuning Prefix
```

目的：

```text
为该 final ANN checkpoint 的
Phase / GIF / MTN SNN conversion 提供新的 calibration states。
```

四种 ANN mode 都必须单独执行：

```text
vanilla
unaware
phase_aware
gif_aware
```

这套 calibration 是 **run-specific** 的，不能在不同 ANN mode 之间共享。

输出目录：

```text
artifacts/<experiment>/<task>/<model>/<ann_mode>/lr<learning_rate>/seed42/
└── post_finetuning/
    └── conversion_calibration/
        └── sites/
```

当前主协议要求：

```text
post_finetuning_recalibration = true
```

SNN conversion 只允许使用这套 calibration。

---

## 3. 两类 Prefix 的定义

### 3.1 ANN-training Prefix

ANN-training Prefix 在 **rotated/fused Base model** 上、使用固定 calibration dataset discover。

用途：

```text
unaware ANN training
phase_aware ANN training
gif_aware ANN training
```

Vanilla ANN training 不使用 Prefix。

输出目录：

```text
_shared/seed42/rotated_prefix/ann_training_prefix/
├── prefix_state.json
└── prefixed_key_values.pt      # 仅当 prefix_token_ids 非空时存在
```

---

### 3.2 Post-finetuning Prefix

12 个 final ANN checkpoint 全部需要独立 rediscover Prefix，包括 Vanilla final ANN checkpoint。

即：

```text
Vanilla final ANN       → 独立 Prefix
Unaware final ANN       → 独立 Prefix
Phase-aware final ANN   → 独立 Prefix
GIF-aware final ANN     → 独立 Prefix
```

Post-finetuning Prefix 用于：

```text
1. Final ANN evaluation
2. Post-finetuning conversion calibration
3. Phase/GIF/MTN SNN evaluation
```

因此同一个 final ANN checkpoint 的 ANN evaluation 和 SNN evaluation 使用的是**同一个 post-finetuning Prefix**。

Vanilla 的特殊性只存在于训练阶段：

```text
Vanilla ANN training:
  no rotation
  no prefix
  no activation replacement
```

但是一旦得到 Vanilla final checkpoint，后续流程与另外三条分支一致：

```text
Vanilla final checkpoint
    ↓
post-finetuning Prefix discovery
    ↓
post-finetuning conversion calibration
    ↓
ANN evaluation / SNN conversion / SNN evaluation
```

唯一仍然不同的是 Vanilla 全程没有 Rotation。

## 7. Step 3：每个模型准备 pre-finetuning shared 工件

这一阶段对每个 model-task pair 只执行一次。

需要依次生成：

```text
1. Rotation / fused Base（自动执行固定 128 calibration samples 的 Base ↔ Rotated logits regression）
2. ANN-training Prefix
3. ANN-training calibration
4. Vanilla analysis calibration
```

其中前 3 项使用 rotated config，推荐统一使用对应 model-task pair 的 `unaware` config；第 4 项使用对应 Vanilla config。

---

### 7.4 四条命令分别做什么

#### 1）`prepare_rotation.py`

```bash
python scripts/prepare_rotation.py --config "$ROT_CFG"
```

作用：

```text
1. 加载两个来自同一 revision 的原始 pretrained Base；
2. 对其中一个执行 RMSNorm scale fusion 与 R1 / R2 / R4-inverse 等 offline/fused rotation；
3. 安装 online R3 / R4，并使用 `SiteController(mode="identity")`；
4. 读取已有 calibration manifest 对应的固定 128 个 samples；
5. 在 no Prefix、no activation replacement、`use_cache=False` 条件下比较 Original Base 与完整 Rotated Base logits；
6. regression 通过后保存 rotation_state、rotation_summary、rotation_regression 和 fused Base；
7. regression 未通过则直接报错并停止，不允许继续后续 Prefix、calibration 或 training。
```

主要输出：

```text
_shared/seed42/rotated_prefix/rotation/
├── rotation_state.pt
├── rotation_summary.json
├── rotation_regression.json
└── fused_base/
```

后续 `unaware / phase_aware / gif_aware` ANN training 都从该 fused Base 出发。

---

#### 2）`discover_prefix.py --stage ann_training`

```bash
python scripts/discover_prefix.py \
  --config "$ROT_CFG" \
  --stage ann_training
```

作用：

```text
在 rotated/fused Base 上
使用固定 128 条 calibration samples
重新统计 PrefixQuant outlier token
并使用同一个 rotated/fused Base 构造 fixed Prefix KV cache
```

主要输出：

```text
_shared/seed42/rotated_prefix/ann_training_prefix/
├── prefix_state.json
└── prefixed_key_values.pt
```

如果最终发现的 `prefix_token_ids` 为空，则 `prefixed_key_values.pt` 可以不存在，这是合法情况。

该 Prefix 只用于 rotated ANN training，不用于最终 ANN/SNN evaluation。

---

#### 3）`calibrate_sites.py --stage ann_training`

```bash
python scripts/calibrate_sites.py \
  --config "$ROT_CFG" \
  --stage ann_training
```

作用：

```text
在 rotated/fused Base
+
ANN-training fixed Prefix KV
条件下，
对固定 128 条 calibration samples 统计每层 10 个 site。
```

每个 site 会生成：

```text
statistics.pt
statistics_summary.json
phase_state.pt
gif_state.pt
mtn_state.pt
clip_state.pt
calibration_summary.json
```

并生成：

```text
statistics_manifest.json
calibration_state_manifest.json
```

这套 state 的用途严格限定为：

```text
phase_aware ANN training → Phase + Clip
gif_aware ANN training   → GIF + Clip
```

`unaware` 不使用它。

---

#### 4）`calibrate_sites.py --stage vanilla_analysis`

```bash
python scripts/calibrate_sites.py \
  --config "$VAN_CFG" \
  --stage vanilla_analysis
```

作用：

```text
在 Original pretrained Base
+
no rotation
+
no prefix
条件下统计同样的 10 个 site。
```

目的仅为与 `ANN-training calibration` 中的 rotated + prefix 统计做对照分析。

当前代码对 Vanilla analysis 不 materialize Phase/GIF/MTN conversion states，因此它不能被 `convert_snn.py` 使用。

主要输出：

```text
该阶段的 shared 配置、日志和统计工件统一位于：

_shared/seed42/vanilla_original/
├── config/
│   └── resolved_config.yaml
├── logs/
└── vanilla_analysis_calibration/
    └── sites/
```

---

### 7.5 Prefix discovery / calibration 的 GPU 使用方式

这些脚本是**单进程**运行，但配置中：

```text
calibration.device_map = auto
```

因此如果一个模型无法放进单卡，可以通过 `CUDA_VISIBLE_DEVICES` 暴露多张 GPU，让 Hugging Face `device_map=auto` 自动切分模型。

例如：

```bash
CUDA_VISIBLE_DEVICES=0,1 python scripts/discover_prefix.py \
  --config "$ROT_CFG" \
  --stage ann_training

CUDA_VISIBLE_DEVICES=0,1 python scripts/calibrate_sites.py \
  --config "$ROT_CFG" \
  --stage ann_training
```

也可以暴露 3 或 4 张卡：

```bash
CUDA_VISIBLE_DEVICES=0,1,2 python ...
CUDA_VISIBLE_DEVICES=0,1,2,3 python ...
```

不要用多个进程同时写同一套 shared Prefix 或 calibration 目录。

## 8. Step 4：训练 12 个 ANN checkpoint

训练使用：

```text
Transformers Trainer
+
DeepSpeed ZeRO-3
+
全参数 fine-tuning
```

当前主实验：

```text
num_train_epochs = 1
per_device_train_batch_size = 1
gradient_accumulation_steps = 16
bf16 = true
eval_strategy = no
save_strategy = no
load_best_model_at_end = false
```

因此训练过程中不进行周期性 validation checkpoint selection；训练完成后统一保存最终 checkpoint：

```text
<ann_mode>/lr<learning_rate>/seed42/ann/final/
```

---

### 8.1 四种 ANN mode 的训练条件

```text
vanilla
  Original Base
  no rotation
  no ANN-training Prefix
  no activation replacement

unaware
  rotated/fused Base
  ANN-training Prefix
  no activation replacement

phase_aware
  rotated/fused Base
  ANN-training Prefix
  Phase replacement
  使用 ANN-training calibration

gif_aware
  rotated/fused Base
  ANN-training Prefix
  GIF replacement
  使用 ANN-training calibration
```

---

### 8.2 训练命令模板

例如使用 2 张 GPU：

```bash
export CUDA_VISIBLE_DEVICES=0,1
NGPU=2
PREFIX=exp1_qwen3_1_7b_tldr

for MODE in vanilla unaware phase_aware gif_aware; do
  torchrun \
    --standalone \
    --nproc_per_node="$NGPU" \
    scripts/train_ann.py \
    --config "configs/generated/${PREFIX}__${MODE}.yaml"
done
```

对三个 model-task pair 分别运行：

```text
exp1_qwen3_1_7b_tldr
exp1_qwen3_8b_tldr
exp2_llama3_8b_tulu3
```

例如 Qwen3-8B：

```bash
export CUDA_VISIBLE_DEVICES=0,1,2,3
NGPU=4
PREFIX=exp1_qwen3_8b_tldr

for MODE in vanilla unaware phase_aware gif_aware; do
  torchrun \
    --standalone \
    --nproc_per_node="$NGPU" \
    scripts/train_ann.py \
    --config "configs/generated/${PREFIX}__${MODE}.yaml"
done
```

同一个 model-task pair 的四种 ANN mode 建议使用相同 GPU 数，以便保证 effective global batch size 一致。

有效 global batch size 为：

```text
per_device_train_batch_size
× gradient_accumulation_steps
× world_size
```

当前 `1 × 16 × NGPU`，因此：

```text
2 GPU → 32
3 GPU → 48
4 GPU → 64
```

<ann_mode>/lr.../seed42/
├── ann/
│   ├── final/
│   │   ├── config.json

ann/final/

## 9. Step 5：每个 final ANN checkpoint 独立生成 Post-finetuning Prefix

这是 ANN training 完成后的第一步。

12 个 final ANN checkpoint **全部必须执行**：

```bash
python scripts/discover_prefix.py \
  --config "$CFG" \
  --stage post_finetuning
```

该命令会：

```text
加载当前 config 对应的 ann/final
        ↓
在同一固定 128 条 calibration samples 上重新 discover Prefix token
        ↓
使用同一个 final ANN checkpoint 构造 fixed Prefix KV cache
```

输出：

```text
<ann_mode>/lr.../seed42/post_finetuning/prefix/
├── prefix_state.json
└── prefixed_key_values.pt   # prefix_token_ids 非空时
```

必须注意：

```text
unaware / phase_aware / gif_aware
不能共享 post-finetuning Prefix。
```

因为它们经过 ANN fine-tuning 后已经是三个不同 checkpoint。

同样，Vanilla final checkpoint 也必须 independently discover post-finetuning Prefix。

---

### 9.1 对一个 model-task pair 的四种 mode 顺序执行

以 Qwen3-1.7B 为例：

```bash
PREFIX=exp1_qwen3_1_7b_tldr

for MODE in vanilla unaware phase_aware gif_aware; do
  CFG="configs/generated/${PREFIX}__${MODE}.yaml"

  python scripts/discover_prefix.py \
    --config "$CFG" \
    --stage post_finetuning
done
```

对另外两个 prefix 重复：

```text
exp1_qwen3_8b_tldr
exp2_llama3_8b_tulu3
```

如果模型需要多卡切分：

```bash
CUDA_VISIBLE_DEVICES=0,1 python scripts/discover_prefix.py \
  --config "$CFG" \
  --stage post_finetuning
```

仍然使用单进程，不要多个进程同时写同一个 run 的 Prefix 目录。

---

## 10. Step 6：每个 final ANN checkpoint 独立执行 Post-finetuning conversion calibration

完成对应 final checkpoint 的 post-finetuning Prefix discovery 后，立即运行：

```bash
python scripts/calibrate_sites.py \
  --config "$CFG" \
  --stage post_finetuning
```

该命令会：

```text
加载当前 run 的 ann/final
        ↓
加载当前 run 自己的 post-finetuning fixed Prefix KV
        ↓
在同一固定 128 条 calibration samples 上
统计每层 10 个 activation replacement site
        ↓
重新生成 Phase / GIF / MTN / Clip states
```

对于 `phase_aware` 和 `gif_aware` final checkpoint，这一步统计的仍然是：

```text
final ANN 本身的 activation
```

不会再次套用 ANN training 时的 Phase/GIF replacement。

### 10.1 对四种 mode 连续执行 Prefix + calibration

## 22. 最终必须遵守的实验协议

整个实验中请始终遵守以下规则：

1. `Vanilla analysis calibration` 只用于分析 Rotation + Prefix 前后的 activation statistics，不用于 conversion。
2. `ANN-training calibration` 只用于 `phase_aware / gif_aware` 的 ANN training，不用于最终 SNN conversion。
3. `unaware` ANN training 使用 Rotation + ANN-training Prefix，但不使用 activation replacement calibration。
4. 四个 final ANN checkpoint 都必须 independently rediscover post-finetuning Prefix，包括 Vanilla。
5. 四个 final ANN checkpoint 都必须 independently 执行 post-finetuning conversion calibration。
6. ANN evaluation 使用当前 final ANN 自己的 post-finetuning Prefix。
7. SNN evaluation 使用与对应 ANN evaluation 完全相同的 post-finetuning Prefix。
8. SNN conversion 只使用 run-specific post-finetuning conversion calibration。
9. `conversion_metadata.json` 中必须满足 `post_finetuning_recalibration=true`。
10. 所有 calibration 使用同一固定 calibration dataset manifest。
11. 当前每层固定为 10 个 activation replacement sites，旧 9-site artifacts 不得继续使用。
12. 任何依赖 final ANN checkpoint 的 Prefix / calibration 均不得存放或读取 `_shared`。

按以上顺序完成后，当前主实验的数据准备、ANN 微调、post-finetuning recalibration、ANN evaluation、SNN conversion 和 SNN evaluation 才构成一套完整且一致的实验链路。
