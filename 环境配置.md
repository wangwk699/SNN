# 环境配置

本目录只提供配置文件和命令，不会自动安装环境。建议在 Linux、CUDA GPU 和 Python 3.10 环境中运行；Llama 3 checkpoint 是 gated model，需先在 Hugging Face 接受许可并登录。

## 1. 创建环境

```bash
conda create -n snn2 python=3.10 -y
conda activate snn2
python -m pip install --upgrade pip setuptools wheel
```

先按照机器 CUDA 驱动选择 PyTorch 官方 wheel。下面以 CUDA 12.4 为例：

```bash
pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt
```

`requirements.txt` 中也固定了 `torch==2.5.1`，已安装相同版本时 pip 不会重复替换。若机器只能使用其他 CUDA wheel，只改变 PyTorch 的 wheel 来源，不要静默改变其余依赖版本。

## 2. 安装 Dao-AILab Fast Hadamard Transform

本项目通过 Git submodule 固定使用 `Dao-AILab/fast-hadamard-transform` 的 revision `e7706faf8d1c3b9f241e36860640ad1dac644ede`。全新 clone 使用：

```bash
git clone --recurse-submodules https://github.com/wangwk699/SNN.git
cd SNN

git submodule update --init --recursive

python -m pip install -e ./fast-hadamard-transform --no-build-isolation
```

仓库已经 clone、但 submodule 尚未初始化时使用：

```bash
cd ~/SNN
git submodule update --init --recursive

python -m pip install -e ./fast-hadamard-transform --no-build-isolation
```

`-e` 表示 editable install，Python 会直接使用当前项目 `fast-hadamard-transform/` 目录对应的源码和所编译扩展。仅有该目录并不能保证 CUDA extension 可用，仍必须执行上述 editable install。

安装后必须核对实际 import 来源：

```bash
python - <<'PY'
import fast_hadamard_transform
print(fast_hadamard_transform.__file__)
from fast_hadamard_transform import hadamard_transform
print("fast-hadamard-transform OK")
PY
```

输出路径必须位于：

```text
<SNN_ROOT>/fast-hadamard-transform/fast_hadamard_transform/
```

正式运行行为固定为：

```text
CPU correctness/test path:
    允许 pure Torch implementation

CUDA formal experiment:
    必须使用 fast-hadamard-transform
    import 或 kernel 失败会直接报错
    禁止静默回退到 pure Torch
```

## 4. 环境自检

```bash
python -c "import torch, transformers, deepspeed, datasets, lm_eval; print(torch.__version__, transformers.__version__, torch.cuda.is_available())"
python - <<'PY'
import fast_hadamard_transform
print(fast_hadamard_transform.__file__)
from fast_hadamard_transform import hadamard_transform
print("fast-hadamard-transform OK")
PY
python -m compileall -q SNN
```

正式运行前用 `nvidia-smi` 检查可见 GPU，并保证同一 model-task pair 的四种 ANN 设置使用相同 GPU 数。训练采用 DeepSpeed ZeRO-3、BF16、eager attention；不得静默启用 FlashAttention 或 gradient checkpointing。
