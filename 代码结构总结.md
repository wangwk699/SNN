## 2. 目录结构

```text
SNN/
├── AGENTS.md                                      — 记录 Clip、ANN/SNN 边界与文档维护规则。
├── README.md                                      — 提供项目概览与使用入口。
├── .gitignore                                     — 定义 Git 忽略的生成文件与本地工件。
├── .gitmodules                                    — 声明 fast-hadamard-transform 子模块。
├── demo.py                                        — 提供项目功能的演示入口。
├── pytest.ini                                     — 配置 pytest 的测试发现与运行参数。
├── requirements.txt                               — 固定项目 Python 依赖版本。
├── 实验执行总结.md                                — 记录当前实验协议、执行顺序与重跑边界。
├── 环境配置.md                                    — 记录项目运行环境的安装与配置方式。
├── 代码结构总结.md                                — 维护当前仓库目录结构及文件功能说明。
├── 代码修复总结/
│   └── 旋转.md                                    — 记录 Rotation 相关历史修复总结。
├── ann_training/
│   └── train_and_evaluate_qwen3_1_7b_phase_aware.sh — 以进程独立临时配置和 LR 锁并行执行 Phase-aware Qwen3-1.7B ANN 训练与 static Phase ANN 评估。
├── configs/
│   ├── deepspeed_zero3.json                       — 配置 DeepSpeed ZeRO-3 训练策略。
│   └── experiment_matrix.yaml                     — 定义十二组主实验及 clip-free SNN deployment 配置矩阵。
├── docs/
│   └── history/
│       ├── SNN 项目本轮修改方案：分离 ANN-training calibration 与 Post-finetuning conversion calibration.md — 保存 calibration 阶段分离的历史方案。
│       ├── SNN_10_site_activation_replacement_实施方案.md — 保存十个 activation site 的历史实施方案。
│       ├── SNN_10site_后续问题完整修复方案.md    — 保存十 site 后续问题的历史修复方案。
│       ├── SNN_Clip仅用于ANN微调_代码修改方案_不含README任务.md — 保存 Clip 限定为 ANN 微调的本次实施方案。
│       ├── SNN_Prefix左填充与conversion工件完整性修正方案.md — 保存 Prefix 左填充与工件完整性的历史方案。
│       ├── SNN_post_finetuning协议收尾修复方案.md — 保存 Post-finetuning 协议收尾的历史方案。
│       ├── SNN_rotated_pre_finetuning_ANN_evaluation_修改方案.md — 保存旋转后微调前 ANN 评估的历史方案。
│       ├── SNN_rotated_pre_finetuning_optional_prefix_修改方案.md — 保存可选 Prefix 评估的历史方案。
│       ├── SNN_rotation_ABC_RoSTE_precision_DU_prompt_end_重构方案.md — 保存 Rotation 精度与回归重构的历史方案。
│       ├── SNN_rotation_regression_and_fht_codex_plan.md — 保存 Rotation 回归与 FHT 的历史方案。
│       ├── SNN_rotation_regression_joint_pass_condition.md — 保存 Rotation 联合通过条件的历史说明。
│       ├── SNN_rotation_regression_margin_aware_codex_plan.md — 保存 margin-aware Rotation 回归的历史方案。
│       ├── SNN_rotation_regression_top1_percentile_codex_plan.md — 保存 Top-1 与百分位 Rotation 回归的历史方案。
│       ├── SNN_temporal_conversion与GIF_qmax30完整修改方案.md — 保存 temporal conversion 与 GIF qmax30 的历史方案。
│       ├── SNN_Phase_SpikingLLM_alignment_and_artifact_reuse_plan.md — 保存 Phase 对齐与 aware 工件复用的本次实施方案。
│       ├── SNN_Phase_alignment_final_cleanup_plan.md — 保存 Prefix、Phase EMA、计数与 provenance 对齐的收尾方案。
│       ├── SNN_Phase_conversion_unit_regression_check_and_fix_plan.md — 保存 static Phase 与 temporal Phase 单元级 conversion regression 方案。
│       ├── SNN_final_ANN_evaluation_training_semantics_alignment_plan.md — 保存 final ANN evaluation 对齐训练期 static replacement 语义的实施方案。
│       ├── SNN_Phase_tau_channel_alignment_P0_P1_P2_P3_plan.md — 保存 Phase τ channel、训练 provenance 与 evaluation metadata 的对齐方案。
│       ├── SNN_Site34_repeatKV_and_common_clip_switch_plan.md — 保存 Site 3/4 repeat-KV Phase statistics 与 ANN common Clip 开关方案。
│       ├── SNN_per_head_grouped_calibration_and_site5_special_modification_plan.md — 保存 per-head grouped calibration 与 Site 5 特例的初始方案。
│       ├── SNN_per_head_grouped_calibration_and_site5_special_modification_plan_FINAL.md — 保存已被 Site 5 GIF identity 方案替代的 per-head grouped calibration 历史方案。
│       ├── SNN_Site5_GIF_Strict_SpikeLLM_Identity_Modification_Plan.md — 保存 Site 5 GIF 从 Q16 特例切换为 SpikeLLM 16-bit sentinel identity 的实施方案。
│       ├── SNN_three_followup_fixes_clip_bundle_group_path_calibration_logs_plan.md — 保存 Clip bundle 三态、aware SNN 路径去重与 calibration config/log 隔离方案。
│       └── post_finetuning_conversion_remove_common_clip_modification_plan.md — 保存移除 Post-finetuning common Clip 的历史方案。
├── fast-hadamard-transform/                       — 提供快速 Hadamard 变换的外部子模块。
├── scripts/
│   ├── _common.py                                 — 提供脚本共享的参数解析、配置加载以及分阶段 resolved config 初始化。
│   ├── calibrate_sites.py                         — 拒绝旧的一次性 calibration 命令并提示 Stage A/B 新入口。
│   ├── collect_calibration_statistics.py          — 执行 Stage A 模型前向并只保存带哈希 provenance 的 statistics。
│   ├── materialize_calibration_states.py          — 执行 Stage B 并从既有 statistics 生成参数化 state variant。
│   ├── convert_snn.py                             — 为指定 neuron 创建 clip-free SNN conversion descriptor。
│   ├── discover_prefix.py                         — 按执行阶段发现 Prefix token 并构造固定 KV cache。
│   ├── evaluate_lm_harness.py                     — 按 ann_mode 执行 static ANN 或按 neuron 执行 Temporal SNN 的 lm-eval 并保存 forward metadata。
│   ├── evaluate_tldr.py                           — 按 ann_mode 执行 static ANN 或按 neuron 执行 Temporal SNN 的 TL;DR 评估、保存 forward metadata 并规范清理分布式进程组。
│   ├── materialize_configs.py                     — 从实验矩阵生成并校验十二份运行配置。
│   ├── prepare_data.py                            — 固定训练、验证、评估与 calibration 数据 manifest。
│   ├── prepare_rotation.py                        — 生成并验证 Rotation 工件并保存 fused Base。
│   ├── regress_phase_conversion.py                — 对 static Phase 与 temporal Phase SNN 运行 provenance、单元、trace、ablation 和 locked-token 回归。
│   ├── sweep_qwen3_8b_unaware_learning_rates.sh   — 依次用四个 learning rate 训练、发现 Post-finetuning Prefix 并评估 Qwen3-8B unaware ANN。
│   ├── train_ann.py                               — 启动 ANN 全参数微调并保存最终 checkpoint。
│   └── verify_artifacts.py                        — 验证 mode-aware final ANN metadata、conversion provenance 与 SNN temporal evaluation 完整性。
├── snn2/
│   ├── __init__.py                                — 定义 snn2 Python 包入口。
│   ├── artifacts.py                               — 组织 group/sample-isolated Stage A/B calibration config/log、学习率后缀含 G 的 aware run 与其他 ANN/SNN 工件路径并提供 JSON 和哈希工具。
│   ├── calibration.py                             — 分离收集 Stage A statistics v2 与物化 Stage B per-head/grouped Phase、GIF、MTN、Clip、Site 5 identity 和 final RMSNorm states。
│   ├── config.py                                  — 解析并严格验证包括 group_size、temporal v6 与 Site 5 GIF identity policy 在内的实验配置协议。
│   ├── controller.py                              — 按 site policy 调度 grouped ANN replacement，并以显式 Clip bundle policy 验证但仅加载选定 temporal neuron。
│   ├── conversion.py                              — 以 SNN neuron-scoped fingerprint 校验 Stage A/B provenance并创建或验证 v10 conversion descriptor。
│   ├── data.py                                    — 构造固定数据集、tokenization 与 batch collator。
│   ├── evaluation.py                              — 构造 G-aware static ANN/full-temporal SNN controller并记录 ANN dependency-scoped 与 SNN neuron-scoped forward metadata。
│   ├── hadamard.py                                — 封装快速 Hadamard 变换及其规格。
│   ├── logging_utils.py                           — 提供结构化日志与阶段运行记录。
│   ├── model_integration.py                       — 按原生 query/KV heads 采集 activation、聚合 GQA saliency并保证 Prefix runtime 经过 Site 3/4/5。
│   ├── modeling.py                                — 加载模型、Rotation、Prefix 与阶段对应状态。
│   ├── neurons.py                                 — 实现 layout-aware grouped Phase/ordinary GIF/MTN/Clip 与严格 SpikeLLM Site 5 SoftmaxIdentityGIF。
│   ├── phase_statistics.py                        — 定义原生 site-layout Phase EMA、channel 与 within-group reduction policy 常量。
│   ├── phase_conversion_regression.py             — 实现支持普通 grouped、attention per-head、Site 5 与 final RMSNorm 的 Phase conversion 回归。
│   ├── prefix.py                                  — 实现 Prefix token 的优化与发现。
│   ├── prefix_cache.py                            — 构造、保存并注入固定 Prefix KV cache。
│   ├── rotation.py                                — 实现 Rotation 规格、权重融合与模型部件访问。
│   ├── sites.py                                   — 定义十个 replacement site、attention/Site 5/Clip eligibility policy 与连续层拓扑校验。
│   ├── state_validation.py                        — 分别校验 Stage A statistics 与 Stage B states，并以 require/allow/forbid 三态处理 grouped state、Clip 和 Site 5 policy。
│   ├── stats.py                                   — 按 last-dim、attention-head、attention-softmax 三类原生布局累积 statistics v2 与 FP32 Phase EMA。
│   ├── temporal_model.py                          — 实现 full-temporal attention 与 cross-time 运算路径。
│   ├── temporal_ops.py                            — 实现 temporal v6 基础算子并集中定义 ordinary GIF、Site 5 identity、grouping 与 final-norm policy metadata。
│   └── training.py                                — 实现 ANN replacement-aware 微调及 dependency-scoped state fingerprint provenance 校验。
└── tests/
    ├── calibration_fixtures.py                    — 为 Stage A/B calibration 测试生成独立 statistics root 与带哈希的 manifest fixture。
    ├── test_calibration_gif.py                    — 验证 ordinary grouped GIF qmax30 calibration 参数生成。
    ├── test_calibration_profiles.py               — 验证 grouped materialization、Site 5 特例、ANN 9-site Clip 与 conversion 无 Clip profile。
    ├── test_calibration_topology.py               — 验证完整连续层、十 site 与 stale Clip 拒绝。
    ├── test_controller_state_loading.py           — 验证 Clip bundle 三态、Site 5 identity/no-Clip 与 aware SNN 仅加载选定 neuron。
    ├── test_conversion_metadata.py                — 验证 v10 neuron-scoped conversion provenance、schema、工件哈希、Rotation 与无 Clip 合同。
    ├── test_evaluation_paths.py                    — 验证 G-aware ANN/SNN controller、forward metadata、结果目录与样本选择协议。
    ├── test_generated_configs.py                  — 动态生成配置并验证 group_size 合法域、temporal v6 与 Site 5 identity policy。
    ├── test_hadamard.py                           — 验证 Hadamard 变换规格与执行行为。
    ├── test_neurons.py                            — 验证 grouped/per-head Phase/GIF/MTN/Clip、strict shape 与 Site 5 exact identity。
    ├── test_phase_conversion_regression.py        — 验证 layout-aware Phase 三分解、recorder、bypass、前置条件与 provenance 拒绝。
    ├── test_post_finetuning_protocol.py           — 验证 calibration config/log/site 的 G 隔离、aware SNN 路径去重及 G-independent 工件共享。
    ├── test_prefix.py                             — 验证 Prefix token 发现与约束。
    ├── test_rotated_pre_finetuning_protocol.py    — 验证旋转后微调前评估与 Prefix 路径。
    ├── test_rotation_regression.py                — 验证 Rotation 回归指标、精度与门控。
    ├── test_sites.py                              — 验证十个 replacement site 定义。
    ├── test_statistics.py                         — 验证 statistics v2 原生 layout、per-head EMA、grouped τ 与 Site 5 可变长度统计。
    ├── test_temporal_model_integration.py         — 验证 full-temporal 集成、Prefix runtime、原生 KV heads 与 GQA saliency 回聚合。
    ├── test_temporal_ops.py                       — 验证 clip-free temporal v6 数学算子和版本。
    ├── test_temporal_prefix.py                    — 验证位置、Prefix offset 和 time-major 布局。
    └── test_training.py                           — 验证 ANN 训练 replacement 与计数逻辑。
```
