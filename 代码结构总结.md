## 1. 总体数据流

```text
固定 task-level raw-sample manifest
        ↓
每个 model-task pair 的 shared pre-finetuning preparation
        │
        ├── Rotation / fused Base
        │
        ├── ANN-training Prefix
        │
        ├── ANN-training calibration
        │
        └── Vanilla analysis calibration
        │
        ↓
四种 ANN full-parameter fine-tuning
        │
        ├── vanilla
        ├── unaware
        ├── phase_aware
        └── gif_aware
        │
        ↓
12 个 final ANN checkpoints
        ↓
每一个 final ANN checkpoint 独立执行
        │
        ├── Post-finetuning Prefix discovery
        │
        └── Post-finetuning conversion calibration
        │
        ├───────────────┐
        ↓               ↓
Final ANN eval     Phase / GIF / MTN conversion
                        ↓
                   SNN evaluation
```

Final ANN evaluation 与其对应的 Phase/GIF/MTN SNN evaluation 使用同一个 run-specific post-finetuning Prefix；SNN conversion 使用该 final ANN checkpoint 自己重新生成的 post-finetuning conversion calibration。

### 1.1 可选：Rotation 后、ANN 微调前的独立 ANN 评估

这不是第五种 `ann_mode`，也不进入 SNN conversion。对任一 rotated config，可通过 `rotated_pre_finetuning.prefix_enabled` 独立选择是否使用 Prefix：`true` 时在 `rotation/fused_base` 上独立发现 Prefix 并构造 fixed KV cache；`false` 时只评估 fused Rotation + online R3/R4，不读取或注入任何 Prefix。

该流程始终安装 `rotation_state.pt` 中的 online R3/R4，使用 identity controller，不生成或读取 conversion calibration。其工件是 model-level shared artifact，不随 `ann_mode` 或 learning rate 改变：

```text
_shared/seed42/rotated_prefix/rotated_pre_finetuning/
├── config/resolved_config.yaml
├── logs/
├── prefix/
│   ├── prefix_state.json
│   └── prefixed_key_values.pt
└── evaluation/tldr/test_samples_<N>[_full]/
```

其中的 Prefix 与 `ann_training_prefix/`、各 final ANN 的 `post_finetuning/prefix/` 完全隔离。

`rotated_pre_finetuning.prefix_enabled` 不复用 ANN-training 的 `prefix.enabled`，只控制这项微调前评估。关闭后即使 `prefix/` 中保留旧工件也会被完全忽略，因而不需要执行该阶段的 Prefix discovery。

仅这项评估的结果路径按开关分开保存（保留方案指定的 `ture` 拼写）：

```text
evaluation/tldr/test_samples_<N>[_full]/
├── prefix_enabled_ture/
└── prefix_enabled_false/
```

`metrics.json` 会记录 `prefix_enabled`；关闭时 `prefix_root=null`。其余 Base、final ANN 与 SNN 的评估路径不变。

## 3. Rotation 与可训练权重

实现采用“可合并 rotation 吸收到权重 + 少量 online rotation”的混合方式。Random Hadamard 的唯一当前语义是 `Q = D U`：`D = diag(random_signs)`，`U` 为 normalized structured Hadamard；forward 对 row vector 先乘 signs 再做 Hadamard，transpose/inverse 先做 `U^T` 再乘 signs。

- RMSNorm scale fusion：FP64 compute，cast 回原权重 dtype；
- `R1`：residual hidden space，所有 offline fusion 使用同一个 FP64 dense `Q` explicit matmul；
- `R2`：value/output-side 使用 FP64 block matmul，o_proj/input-side 使用 FP32 FHT；
- `R3`：RoPE 后对 Q/K 在线计算并保持输入 activation dtype，不再无条件 `.float()`；
- `R4`：offline down projection 和 online MLP product 都使用 FP32 FHT，online 后 cast 回原 activation dtype；
- rotation matrix/policy 固定，但保存到 `fused_base` 的旋转后权重是后续全参数微调对象。原始 Hugging Face Base 只作为源 checkpoint，不被原地修改。

`prepare_rotation.py` 加载三份同源模型：A 为 untouched HF Base，B 为 SNN2 identity integration/no rotation，C 为完整 Rotated + SNN2 identity。它对 `A↔B`、`B↔C`、`A↔C` 同时生成 all-token hard-gated metrics 和 prompt-only/evaluation-length 的 prompt-end diagnostic；prompt-end 明确不 gating。回归 JSON 为 format v4，并附结构化 diagnosis。

Rotation state 为 format v2，必须同时声明 `random_hadamard_orientation=DU` 与 `precision_policy=roste_aligned_v1`；旧 state 会 fail-fast，必须从 `prepare_rotation.py` 重建所有 rotation-derived artifacts。

CPU 可使用 pure Torch fallback；CUDA tensor 必须调用项目 pinned `Dao-AILab/fast-hadamard-transform`，import 或 runtime 失败时直接报错，不 silent fallback。

## 4. 十个 activation replacement site

固定映射为：

```text
1:R1, 2:R3, 3:R3, 4:R2, 5:I, 6:R2, 7:R1, 8:I, 9:I, 10:R4
```

Softmax 后、SiLU 后以及 up_proj 后均不增加额外 rotation；新增 Site 9 位于 up_proj 输出后，原 R4 后 MLP product site 顺延为 Site 10。训练期 Phase/GIF replacement 在每个 site 内立即聚合为静态 tensor；层间不携带时间维。deployment 才把时间维以 time-major flattened `[T*B, ...]` 形式跨层保留：embedding 和 Linear bias 只在第一个 timestep 注入；非线性、norm 与矩阵乘不再逐 timestep 独立计算，而按 full-temporal cross-time 语义传播，最后只在 lm_head 后沿 T 求和。

## 5. Calibration：三阶段统计与工件用途

当前项目不再采用“在 Base checkpoint 上 calibration 一次，并将同一套 calibration state 冻结到 ANN 微调结束以后继续用于 SNN conversion”的旧协议。

现在必须严格区分以下三类 calibration：

```
1. Vanilla analysis calibration
2. ANN-training calibration
3. Post-finetuning conversion calibration
```

三者虽然都使用同一套固定 calibration samples，并且都对每层相同的 10 个 activation replacement site 进行统计，但它们的**模型来源、Prefix/Rotation 条件、保存位置以及用途完全不同**，不能混用。

整体关系如下：

```
                        fixed calibration manifest
                                  │
                 ┌────────────────┼────────────────┐
                 │                │                │
                 ▼                ▼                ▼
       Vanilla analysis     ANN-training      Post-finetuning
         calibration        calibration        calibration
                 │                │                │
                 │                │                │
          analysis only     ANN training       SNN conversion
                                             + SNN deployment
```

------

### 5.1 固定 Calibration Dataset

所有 calibration 阶段均读取 `prepare_data.py` 预先生成的固定 calibration manifest。

当前设定为：

```
calibration.samples = 128
with_replacement = false
seed = 42
```

也就是说，同一个 task 下：

```
Vanilla analysis calibration
ANN-training calibration
所有 final ANN 的 post-finetuning calibration
```

使用的都是**同一组固定 calibration samples**。

对应 task-level 工件位于：

```
artifacts/<experiment>/<task>/_shared/seed42/data/
└── calibration_manifest.json
```

这样不同模型状态之间的 activation statistics 才具有直接可比性。

每套 calibration manifest 都会记录：

```
calibration_data_manifest_path
calibration_data_manifest_sha256
```

用于验证 calibration 所使用的数据完全一致。

------

### 5.2 Vanilla Analysis Calibration

#### 对象

Vanilla analysis calibration 使用：

```
Original pretrained Base model
```

条件为：

```
no rotation
no Prefix
no activation replacement
```

即：

```
Original Base
     ↓
直接在固定 calibration dataset 上前向
     ↓
统计每层 10 个 site
```

#### 目的

该 calibration **只用于分析**：

> 比较加入 `Rotation + Prefix` 前后，相同 activation replacement site 的激活值范围、分布和 outlier 特征发生了什么变化。

例如可以对比：

```
value_min / value_max
absolute max
mean absolute magnitude
second moment
operator-aware saliency
activation range / quantile / outlier statistics
```

因此它不是：

```
ANN training calibration
```

也不是：

```
SNN conversion calibration
```

#### 工件属性

其 manifest 必须满足：

```
purpose = vanilla_analysis_calibration


analysis_only = true


eligible_for_ann_training = false


eligible_for_conversion = false


post_finetuning_recalibration = false


rotation_enabled = false


prefix_protocol_enabled = false
```

#### 保存内容

Vanilla analysis calibration 只需要保存统计量。

每个 site 至少包含：

```
statistics.pt
statistics_summary.json
```

由于：

```
materialize_states = false
```

它不生成用于 SNN conversion 的：

```
phase_state.pt
gif_state.pt
mtn_state.pt
clip_state.pt
```

因此不能被 `convert_snn.py` 使用。

#### 保存目录

```
artifacts/<experiment>/<task>/<model>/_shared/seed42/
└── vanilla_original/
    ├── config/
    │   └── resolved_config.yaml
    ├── logs/
    └── vanilla_analysis_calibration/
        └── sites/
            ├── statistics_manifest.json
            ├── calibration_state_manifest.json
            └── layer_xxx/
                └── site_xx_name/
                    ├── statistics.pt
                    └── statistics_summary.json
```

其中：

```
config/
logs/
vanilla_analysis_calibration/
```

全部属于 model-level shared Vanilla analysis policy，不进入：

```
base/
```

也不进入：

```
vanilla/lr.../seed.../
```

### 5.3 ANN-training Calibration

#### 对象

ANN-training calibration 使用：

```
Rotated / fused Base model
+
ANN-training fixed Prefix KV cache
```

即：

```
Original Base
     ↓
prepare_rotation
     ↓
Rotated/Fused Base
     ↓
discover ANN-training Prefix
     ↓
fixed ANN-training Prefix KV
     ↓
在固定 calibration dataset 上统计 10 个 site
```

#### 目的

该 calibration **只用于 ANN 微调阶段的 activation replacement**。

具体使用关系：

```
vanilla
  → 不使用 ANN-training calibration


unaware
  → 不使用 ANN-training calibration


phase_aware
  → 使用 Phase state + common Clip state


gif_aware
  → 使用 GIF state + common Clip state
```

特别注意：

```
unaware
```

虽然 ANN training 使用：

```
Rotation
+
ANN-training Prefix
```

但因为：

```
replacement.train_mode = none
```

所以不会读取 ANN-training calibration state。

#### 工件属性

manifest 必须满足：

```
purpose = ann_training_calibration


analysis_only = false


eligible_for_ann_training = true


eligible_for_conversion = false


post_finetuning_recalibration = false


rotation_enabled = true


prefix_protocol_enabled = true
```

因此：

> ANN-training calibration 绝不能被 `convert_snn.py` 当作最终 SNN conversion calibration 使用。

#### 保存内容

每个 site 会保存：

```
statistics.pt
statistics_summary.json


phase_state.pt
gif_state.pt
mtn_state.pt
clip_state.pt


calibration_summary.json
```

其中虽然为了统一构造逻辑也会生成：

```
MTN state
```

但 ANN-training 阶段实际只使用：

```
phase_aware → Phase + Clip


gif_aware   → GIF + Clip
```

MTN state 不参与当前 ANN training。

#### 保存目录

```
artifacts/<experiment>/<task>/<model>/_shared/seed42/
└── rotated_prefix/
    ├── rotation/
    ├── ann_training_prefix/
    └── ann_training_calibration/
        └── sites/
            ├── statistics_manifest.json
            ├── calibration_state_manifest.json
            └── layer_xxx/
                └── site_xx_name/
                    ├── statistics.pt
                    ├── statistics_summary.json
                    ├── phase_state.pt
                    ├── gif_state.pt
                    ├── mtn_state.pt
                    ├── clip_state.pt
                    └── calibration_summary.json
```

它属于 model-level shared pre-finetuning artifact，因此：

```
unaware
phase_aware
gif_aware
```

在 ANN training 前共享同一套 ANN-training calibration。

### 5.4 Post-finetuning Conversion Calibration

这是当前协议中真正用于最终 SNN conversion 的 calibration。

#### 对象

它不再使用 Base checkpoint，而是对**每一个已经完成 ANN 微调的 final checkpoint 单独执行**。

对于每个：

```
vanilla
unaware
phase_aware
gif_aware
```

都执行：

```
ann/final
     ↓
重新 discover post-finetuning Prefix
     ↓
用同一个 final ANN checkpoint 构造 fixed Prefix KV
     ↓
在同一固定 calibration dataset 上重新统计每层 10 个 site
     ↓
重新生成 Phase / GIF / MTN / Clip states
```

因此：

```
4 个 ANN mode
```

拥有 4 套彼此独立的 post-finetuning calibration。

如果 learning rate 或 seed 不同，则继续独立：

```
ann_mode
× learning_rate
× seed
```

对应不同 calibration。

#### 为什么必须重新 calibration

ANN full-parameter fine-tuning 后，模型参数已经从：

```
W_pre
```

变为：

```
W_final
```

因此各 site 上的：

```
activation range
min/max
absolute max
saliency
distribution
```

都可能发生变化。

最终 SNN conversion 的：

```
Phase threshold/state
GIF quantization state
MTN scale/threshold state
```

应该根据**真正准备被转换的 final ANN checkpoint**重新确定，而不是继续使用微调前 Base 的统计。

Post-finetuning conversion calibration 必须基于 final ANN 与 GIF qmax30 重新计算 common Clip；该 run-specific Clip 是 Phase/GIF/MTN temporal deployment 的共同组成部分。

因此当前主协议明确为：

```
post_finetuning_recalibration = true
```

------

### 5.5 Post-finetuning Calibration 时不会再次套 ANN-training Replacement

即使 final checkpoint 来自：

```
phase_aware
```

或者：

```
gif_aware
```

post-finetuning calibration 时也不会再次对 activation 套用 Phase/GIF training replacement。

Calibration controller 始终进入：

```
mode = collect
```

即：

```
Final ANN activation
       ↓
原样记录 statistics
       ↓
不改变 x
```

因此统计的对象是：

> **最终 ANN checkpoint 本身真实产生的 activation。**

而不是：

```
Final ANN
+
再次 Phase/GIF replacement
```

------

### 5.6 Post-finetuning Prefix 与 Calibration 的关系

每个 final ANN checkpoint 都会独立 rediscover Prefix。

包括：

```
vanilla
unaware
phase_aware
gif_aware
```

因此每个 run 有自己的：

```
post_finetuning/prefix/prefix_state.json
```

若：

```
prefix_token_ids
```

非空，还会有：

```
prefixed_key_values.pt
```

如果：

```
prefix_token_ids = []
```

则没有 KV 文件也是合法的。

Post-finetuning calibration 必须使用：

```
该 final ANN checkpoint 自己的 post-finetuning Prefix
```

不能使用：

```
ANN-training Prefix
```

也不能使用：

```
另一个 ANN mode 的 post-finetuning Prefix
```

------

### 5.7 Vanilla Final ANN 的 Post-finetuning Calibration

Vanilla 的特殊性只存在于 ANN training 阶段。

Vanilla training 为：

```
Original Base
no rotation
no Prefix
no activation replacement
```

但是得到：

```
Vanilla final ANN checkpoint
```

以后，它和其它三条分支进入同样的 post-finetuning pipeline：

```
Vanilla final ANN
       ↓
rediscover post-finetuning Prefix
       ↓
fixed Prefix KV
       ↓
post-finetuning calibration
       ↓
ANN evaluation
+
Phase/GIF/MTN SNN conversion
+
SNN evaluation
```

Vanilla 唯一继续保持的区别是：

```
rotation_enabled = false
```

因此其 post-finetuning calibration provenance 为：

```
prefix_protocol_enabled = true


rotation_enabled = false
```

### 5.10 Calibration State 的构造

从 statistics 中生成三类 neuron state。

#### Phase

主要保存：

```
T
base
surrogate_slope
max_spikes
group_size
tau
v0
```

其中阈值相关量由 calibration activation range 决定。

------

#### GIF

主要保存：

```
base_bits
add_bits
low_ratio
group_size


low_scale
low_zero


high_scale
high_zero


mask_low


operator-aware saliency metadata
```

当前实现使用：

```
site-specific static direct-min-max
```

不是 SpikeLLM 原始的 per-sample/per-token dynamic quantization。

------

#### MTN

主要保存：

```
T
K
group_size
base_scale
threshold_factor
```

------

#### ANN-training Common Clip

ANN-training calibration 会为 `phase_aware` / `gif_aware` ANN fine-tuning 构造 neuron-independent common clipping interval：

```
intersection(
    Phase representable interval,
    MTN representable interval,
    GIF low/high common representable interval
)
```

该 profile 的每个 site 保存：

```
clip_state.pt
```

ANN replacement 路径保持：

```
Phase → Phase output + Clip
GIF → GIF output + Clip
```

Post-finetuning conversion calibration 生成 `clip_state.pt`。Phase/GIF/MTN full-temporal deployment 均在 neuron temporal 输出后执行 cumulative-then-difference common Clip；GIF 量化器内部的整数范围 clamp 属于 GIF 自身算法，仍然保留。

```
ANN-training calibration
```

记录：

```
fixed calibration manifest
ANN-training Prefix
rotation state
```

而：

```
Post-finetuning conversion calibration
```

还会额外记录：

```
source final ANN checkpoint
source ANN config SHA-256
ann_mode
learning_rate
```

------

### 5.12 Calibration 与 Conversion 的强约束

`convert_snn.py` 只允许使用：

```
purpose =
post_finetuning_conversion_calibration
```

并要求：

```
eligible_for_conversion = true


post_finetuning_recalibration = true
```

因此：

```
Vanilla analysis calibration
```

和：

```
ANN-training calibration
```

即使磁盘上存在 neuron state，也不能合法用于最终 conversion。

Conversion 前还必须存在：

```
post_finetuning/prefix/prefix_state.json
```

若其中：

```
prefix_token_ids != []
```

则必须同时存在：

```
prefixed_key_values.pt
```

否则 conversion 直接报错。

------

### 5.13 三类 Calibration 的最终对照

| Calibration                | 模型               | Rotation    | Prefix              | 生成 neuron states | 主要用途                                  |
| -------------------------- | ------------------ | ----------- | ------------------- | ------------------ | ----------------------------------------- |
| Vanilla analysis           | Original Base      | 否          | 否                  | 否                 | 分析 Rotation+Prefix 前后 activation 变化 |
| ANN-training               | Rotated/Fused Base | 是          | ANN-training Prefix | 是                 | Phase/GIF-aware ANN training              |
| Post-finetuning conversion | 每个 final ANN     | 依 ANN mode | Post-FT Prefix      | 是                 | Phase/GIF/MTN SNN conversion              |

其中：

```
vanilla final
```

在 post-finetuning 阶段：

```
Rotation = false
Prefix = true
```

------

### 5.14 核心原则

当前项目的 Calibration 原则可以概括为：

```
分析用统计
≠
ANN 微调用统计
≠
SNN 转换用统计
```

具体为：

```
Vanilla analysis calibration
    → analysis only


ANN-training calibration
    → pre-finetuning
    → phase_aware / gif_aware training only


Post-finetuning conversion calibration
    → final ANN specific
    → SNN conversion only
```

最终 ANN 与 SNN 的公平比较还要求：

```
Final ANN evaluation
和
对应 SNN evaluation
```

使用同一个：

```
run-specific post-finetuning Prefix
```

而 SNN conversion 使用该 final ANN checkpoint 自己重新生成的：

```
Post-finetuning conversion calibration
```

这就是当前项目的正式 calibration protocol。

## 8. Full-Temporal Deployment v2 实现结构

### 8.1 核心模块与调用边界

`snn2/temporal_ops.py` 是 v2 temporal 数学的唯一公共实现，集中定义工件版本、time-major `[T*B,...]` 布局、Linear bias、Prefix/T、common Clip 和 GIF qmax/chunk policy。它提供 cumulative-then-difference unary operator、temporal RMSNorm/Softmax/SiLU/Clip、cross-time seq-matmul、对称 Hadamard，以及 `[T*B] ↔ [T,B]` 的严格 reshape。

`snn2/temporal_model.py` 实现 deployment attention：Q/K/V 投影后，Qwen3 可选 `q_norm/k_norm` 先 temporal 化；QK 和 PV 都使用 cross-time seq-matmul；attention mask 在所有 frame 必须完全相同，softmax 只对累计 score 应用一次语义。GQA 在每个 temporal frame 内执行 `repeat_kv`，Prefix 与 current K/V 分开处理。

`snn2/model_integration.py` 负责把模型接到这套算术：

```text
embedding：t=0 注入
Linear bias：t=0 注入
input/post-attention/final RMSNorm：temporal RMSNorm
Qwen3 q_norm/k_norm：temporal RMSNorm（可选模块）
attention QK/PV：cross-time seq-matmul
SiLU：cumulative-then-difference
MLP gate-up：symmetric cross-time Hadamard
lm_head：逐 frame 线性计算，之后 sum(T)
```

这些替换只在 controller 的 `deploy_phase`、`deploy_gif`、`deploy_mtn` 模式生效。ANN、collect 与 ANN-training replacement 路径保持静态 tensor 行为；deployment 还强制 `model.eval()` 和 attention dropout 为零。

### 8.2 Site、Neuron 与 Common Clip

每个 decoder layer 仍有固定 10 个 site。`SiteController.apply()` 在 deployment 中执行：

```text
x [T*B,...]
  → reshape [T,B,...]
  → selected neuron.temporal(...)
  → clip.temporal(...)                 # cumulative value clip + temporal difference
  → reshape [T*B,...]
```

Phase、GIF、MTN 三种 neuron 都必须有对应 state，同时每个 site 必须存在同一份 neuron-independent `clip_state.pt`。Clip 不是逐 frame 独立 clamp；逐 frame clamp 会破坏累计 ANN 等价性。

GIF high quantizer 的有效 code 固定为 `0..30`，两个 local temporal chunk 均为 `0..15`。`30=15+15`，zero point 只减一次；calibration `_qparams` 显式接收 qmin/qmax，不再用 `2**bits-1` 隐式得到 31。

### 8.3 Prefix KV、Mask 与 Position

`snn2/prefix_cache.py` 根据 controller 动态选择布局：ANN 为逻辑 batch B 各注入完整 Prefix；SNN 为 time-major `[T,B]` 的每个 frame 注入 `K/T,V/T`。保存的 Prefix batch 只允许 1 或逻辑 B，不能把物理 `T*B` 错当逻辑 batch。

```text
Σ_t K_prefix,t = K_prefix
Σ_t V_prefix,t = V_prefix
```

Mask 和 position offset 不属于可加 activation：它们不除以 T。evaluation 先从当前序列 attention mask 逐样本生成 0-based `position_ids`（真实 token 连续、padding 为 0），`temporal_forward()` 再按 time-major 将 `[B,L]` 重复为 `[T*B,L]`，最后 Prefix wrapper 只加固定 P 一次；ANN 使用同一份逻辑位置。`cache_position [L]` 不按 batch/time 重复，也只加 P 一次。

```text
attention_mask
  -> per-sample current position_ids
  -> temporal time-major repeat
  -> Prefix wrapper adds fixed P once
  -> model/RoPE
```

### 8.4 工件校验与评测入口

四类 site state 与 temporal implementation 继续为 format/version v2；calibration manifest 与 conversion descriptor 升为 format v3。`snn2/state_validation.py` 遍历全部 layer/site，而不是只读取第一个 site；它验证 ANN config 层数、manifest 的 `expected_num_hidden_layers`、实际连续 `layer_000..layer_{N-1}`、完整 10-site topology、四类 state、所有 neuron T、temporal policy、GIF qmax30 和两步 chunk policy。

`snn2/conversion.py` 在创建 descriptor 前要求 post-finetuning profile 为 `snn_conversion_with_common_clip`。共享 `validate_conversion_metadata()` 又在两个正式 SNN 评测入口和 `scripts/verify_artifacts.py` 中核对 descriptor format/policy、全部 site state、T、ANN config hash、calibration manifest hash、Rotation state hash、Prefix state/KV hash 和 common Clip 标志。绑定链为：

```text
ANN config num layers
calibration manifest expected layers
actual calibration layer/site directories
rotation_state hash
Prefix state/KV hash
conversion descriptor
```

因此旧 v2 manifest/descriptor、qmax31、缺字段、hash 漂移或跨阶段混用都 fail closed，不会被新默认值静默补齐。

### 8.5 测试保护的数学不变量

新增测试覆盖 B>1、GQA、有/无 Prefix、causal/padding mask、Qwen3 q_norm/k_norm 可选路径、final norm、Linear bias、tiny decoder ANN 累计等价性，以及 GIF `0/15/16/29/30` 边界和 `31` 拒绝。Prefix 测试验证每步 KV/T、时间和恢复完整 KV，并验证 mask/position 不缩放。旧 state/manifest/conversion format、跨 site T 不一致和 policy 不一致均有拒绝测试。

这些实现语义由本仓库的 temporal v2 policy 和单元测试定义；`SNN.pdf` Eq. (15)–(17) 不是 deployment operator 的运行依据。
