# 代码结构总结

## 2. 目录结构

```text
SNN/

├── .gitignore                                     — 定义 Git 忽略的生成文件与本地工件。

├── demo.py                                        — 提供项目功能的演示入口。
├── pytest.ini                                     — 配置 pytest 的测试发现与运行参数。
├── requirements.txt                               — 固定项目 Python 依赖版本。
├── 实验执行总结.md                                — 记录当前实验协议、执行顺序与重跑边界。
├── 环境配置.md                                    — 记录项目运行环境的安装与配置方式。
├── 代码结构总结.md                                — 维护当前仓库目录结构及文件功能说明。
├── 代码修复总结/
│   └── 旋转.md                                    — 记录 Rotation 相关历史修复总结。
├── configs/
│   ├── deepspeed_zero3.json                       — 配置 DeepSpeed ZeRO-3 训练策略。
│   └── experiment_matrix.yaml                     — 定义十二组主实验及 clip-free SNN deployment 配置矩阵。
├── docs/
│   └── history/
│       ├── SNN 项目本轮修改方案：分离 ANN-training calibration 与 Post-finetuning conversion calibration.md — 保存 calibration 阶段分离的历史方案。
│       ├── SNN_10_site_activation_replacement_实施方案.md — 保存十个 activation site 的历史实施方案。
│       ├── SNN_10site_后续问题完整修复方案.md    — 保存十 site 后续问题的历史修复方案。
│       ├── SNN_Clip仅用于ANN微调_代码修改方案_不含README任务.md — 保存 Clip 限定为 ANN 微调的本次实施方案。
│       ├── SNN_Prefix左填充与conversion工件完整性修正方案.md — 保存 Prefix 左填充与工件完整性的历史方案。
│       ├── SNN_post_finetuning协议收尾修复方案.md — 保存 Post-finetuning 协议收尾的历史方案。
│       ├── SNN_rotated_pre_finetuning_ANN_evaluation_修改方案.md — 保存旋转后微调前 ANN 评估的历史方案。
│       ├── SNN_rotated_pre_finetuning_optional_prefix_修改方案.md — 保存可选 Prefix 评估的历史方案。
│       ├── SNN_rotation_ABC_RoSTE_precision_DU_prompt_end_重构方案.md — 保存 Rotation 精度与回归重构的历史方案。
│       ├── SNN_rotation_regression_and_fht_codex_plan.md — 保存 Rotation 回归与 FHT 的历史方案。
│       ├── SNN_rotation_regression_joint_pass_condition.md — 保存 Rotation 联合通过条件的历史说明。
│       ├── SNN_rotation_regression_margin_aware_codex_plan.md — 保存 margin-aware Rotation 回归的历史方案。
│       ├── SNN_rotation_regression_top1_percentile_codex_plan.md — 保存 Top-1 与百分位 Rotation 回归的历史方案。
│       ├── SNN_temporal_conversion与GIF_qmax30完整修改方案.md — 保存 temporal conversion 与 GIF qmax30 的历史方案。
│       ├── SNN_Phase_SpikingLLM_alignment_and_artifact_reuse_plan.md — 保存 Phase 对齐与 aware 工件复用的本次实施方案。
│       ├── SNN_Phase_alignment_final_cleanup_plan.md — 保存 Prefix、Phase EMA、计数与 provenance 对齐的收尾方案。
│       ├── SNN_Phase_conversion_unit_regression_check_and_fix_plan.md — 保存 static Phase 与 temporal Phase 单元级 conversion regression 方案。
│       ├── SNN_final_ANN_evaluation_training_semantics_alignment_plan.md — 保存 final ANN evaluation 对齐训练期 static replacement 语义的实施方案。
│       ├── SNN_Phase_tau_channel_alignment_P0_P1_P2_P3_plan.md — 保存 Phase τ channel、训练 provenance 与 evaluation metadata 的对齐方案。
│       ├── SNN_Site34_repeatKV_and_common_clip_switch_plan.md — 保存 Site 3/4 repeat-KV Phase statistics 与 ANN common Clip 开关方案。
│       └── post_finetuning_conversion_remove_common_clip_modification_plan.md — 保存移除 Post-finetuning common Clip 的历史方案。
├── fast-hadamard-transform/                       — 提供快速 Hadamard 变换的外部子模块。
├── scripts/
│   ├── _common.py                                 — 提供脚本共享的参数解析、配置加载和运行初始化。
│   ├── calibrate_sites.py                         — 收集十个 site 的统计并生成阶段对应 calibration state。
│   ├── convert_snn.py                             — 为指定 neuron 创建 clip-free SNN conversion descriptor。
│   ├── discover_prefix.py                         — 按执行阶段发现 Prefix token 并构造固定 KV cache。
│   ├── evaluate_lm_harness.py                     — 按 ann_mode 执行 static ANN 或按 neuron 执行 Temporal SNN 的 lm-eval 并保存 forward metadata。
│   ├── evaluate_tldr.py                           — 按 ann_mode 执行 static ANN 或按 neuron 执行 Temporal SNN 的 TL;DR 评估并保存 forward metadata。
│   ├── materialize_configs.py                     — 从实验矩阵生成并校验十二份运行配置。
│   ├── prepare_data.py                            — 固定训练、验证、评估与 calibration 数据 manifest。
│   ├── prepare_rotation.py                        — 生成并验证 Rotation 工件并保存 fused Base。
│   ├── regress_phase_conversion.py                — 对 static Phase 与 temporal Phase SNN 运行 provenance、单元、trace、ablation 和 locked-token 回归。
│   ├── sweep_qwen3_8b_unaware_learning_rates.sh   — 依次用四个 learning rate 训练、发现 Post-finetuning Prefix 并评估 Qwen3-8B unaware ANN。
│   ├── train_ann.py                               — 启动 ANN 全参数微调并保存最终 checkpoint。
│   └── verify_artifacts.py                        — 验证 mode-aware final ANN metadata、conversion provenance 与 SNN temporal evaluation 完整性。
├── snn2/
│   ├── __init__.py                                — 定义 snn2 Python 包入口。
│   ├── artifacts.py                               — 组织 mode/prefix/common-Clip-aware 实验工件路径并提供 JSON 与哈希工具。
│   ├── calibration.py                             — 按 SpikingLLM EMA 生成 site 与全局 final RMSNorm state bundle。
│   ├── config.py                                  — 解析并严格验证实验配置协议。
│   ├── controller.py                              — 调度 ANN replacement、clip-free deployment 及默认关闭的 regression site recorder。
│   ├── conversion.py                              — 按 mode 校验 calibration reuse policy、aware 训练工件哈希并创建或验证 v7 conversion descriptor。
│   ├── data.py                                    — 构造固定数据集、tokenization 与 batch collator。
│   ├── evaluation.py                              — 统一构造 mode-aware static ANN/full-temporal SNN controller、forward metadata 与 generation/proxy。
│   ├── hadamard.py                                — 封装快速 Hadamard 变换及其规格。
│   ├── logging_utils.py                           — 提供结构化日志与阶段运行记录。
│   ├── model_integration.py                       — 接入 Prefix K/V runtime、repeat-KV 后 Phase collect view 与 full-temporal 运算。
│   ├── modeling.py                                — 加载模型、Rotation、Prefix 与阶段对应状态。
│   ├── neurons.py                                 — 实现 Phase、GIF、MTN neuron 及 ANN-only Clipper。
│   ├── phase_statistics.py                        — 将 attention activation reshape 为仅供 Phase EMA 使用的 SpikingLLM statistical view。
│   ├── phase_conversion_regression.py             — 实现 Phase conversion artifact 校验、micro/primitive 指标、paired recorder 与 first-divergence 汇总。
│   ├── prefix.py                                  — 实现 Prefix token 的优化与发现。
│   ├── prefix_cache.py                            — 构造、保存并注入固定 Prefix KV cache。
│   ├── rotation.py                                — 实现 Rotation 规格、权重融合与模型部件访问。
│   ├── sites.py                                   — 定义十个 replacement site 及连续层拓扑校验。
│   ├── state_validation.py                        — 校验 ANN 含 Clip 或 SNN 无 Clip 的 calibration state bundle。
│   ├── stats.py                                   — 独立累积 generic activation/saliency 与 Phase statistical-view FP32 EMA 统计。
│   ├── temporal_model.py                          — 实现 full-temporal attention 与 cross-time 运算路径。
│   ├── temporal_ops.py                            — 实现无 Clip temporal v3 基础算子、embedding/Softmax/final-norm 策略元数据。
│   └── training.py                                — 实现 ANN replacement-aware 微调及训练/aware final evaluation 的 frozen provenance 校验。
└── tests/
    ├── test_calibration_gif.py                    — 验证 GIF calibration 参数生成。
    ├── test_calibration_profiles.py               — 验证 ANN 含 Clip 与 conversion 无 Clip 的 materialization profile。
    ├── test_calibration_topology.py               — 验证完整连续层、十 site 与 stale Clip 拒绝。
    ├── test_controller_state_loading.py           — 验证 ANN Clip 加载和 clip-free SNN deployment。
    ├── test_conversion_metadata.py                — 验证 v7 mode-aware conversion、工件哈希、层数、Rotation 与无 Clip 合同。
    ├── test_evaluation_paths.py                    — 验证 mode-aware ANN/SNN controller、forward metadata、结果目录与样本选择协议。
    ├── test_generated_configs.py                  — 动态生成并验证十二份主实验配置。
    ├── test_hadamard.py                           — 验证 Hadamard 变换规格与执行行为。
    ├── test_neurons.py                            — 验证 Phase、GIF、MTN 与 ANN static Clipper。
    ├── test_phase_conversion_regression.py        — 验证 Phase 三分解、recorder、bypass、前置条件与 provenance 拒绝。
    ├── test_post_finetuning_protocol.py           — 验证 Post-finetuning 工件路径和 Prefix 协议。
    ├── test_prefix.py                             — 验证 Prefix token 发现与约束。
    ├── test_rotated_pre_finetuning_protocol.py    — 验证旋转后微调前评估与 Prefix 路径。
    ├── test_rotation_regression.py                — 验证 Rotation 回归指标、精度与门控。
    ├── test_sites.py                              — 验证十个 replacement site 定义。
    ├── test_statistics.py                         — 验证 activation 与 saliency 统计归约。
    ├── test_temporal_model_integration.py         — 验证模型 full-temporal 集成及 Prefix batch invariance。
    ├── test_temporal_ops.py                       — 验证 clip-free temporal v3 数学算子和版本。
    ├── test_temporal_prefix.py                    — 验证位置、Prefix offset 和 time-major 布局。
    └── test_training.py                           — 验证 ANN 训练 replacement 与计数逻辑。
```
